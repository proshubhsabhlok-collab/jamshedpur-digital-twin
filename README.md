# Jamshedpur Digital Twin

An interactive browser-based 3D smart-city simulation for a Class 12 project.

## Current version

- Interactive 3D city scene using React Three Fiber
- Stylized Jamshedpur landmarks: Tata Steel and Jubilee Park
- Road network and animated vehicles
- Traffic, industrial emissions, rainfall and time-of-day controls
- Simulated AQI, congestion, waterlogging risk and City Health Index
- Location panel for major Jamshedpur areas

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
